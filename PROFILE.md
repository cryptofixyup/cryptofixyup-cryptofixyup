## Engineering Principles

**Evidence over assumptions.** Systems should be measurable, testable, and explainable.

**Security by construction.** Validate inputs, fail closed, minimize trust, and make security boundaries explicit.

**Simple production systems beat speculative complexity.** Add infrastructure when a real constraint requires it.

**Performance is a product property.** Optimize latency, memory, reliability, and operating cost together.

**Open source should be useful.** Prefer reproducible implementations, deterministic tests, clear interfaces, and documentation that matches the code.
